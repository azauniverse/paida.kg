# PAIDA KG — биринчи прототип

Мобилдик түзмөктөргө ылайыкташкан Кыргызстанга арналган пайдалуу сунуштар платформасынын статикалык демо-версиясы.

## Азыр иштеген функциялар

- Кыргызча / орусча интерфейс которуу.
- Товар, арзандатуу, жумуш жана кызмат бөлүмдөрү.
- Издөө жана категория боюнча чыпкалоо.
- Аймак тандоо, баасы боюнча иреттөө.
- Сунуштарды сактоо (браузердин localStorage'ында).
- Демо жарыя кошуу формасы (браузердин localStorage'ына гана сакталат).
- Карточканын толук маалыматын ачуу.
- Мобилдик жана чоң экрандар үчүн responsive дизайн.

## Маанилүү чектөө

Бул **чыныгы өндүрүш сайты эмес, интерфейстин прототиби**. Көрсөтүлгөн карточкалардын баары демонстрациялык, чыныгы сунуш же иш орду эмес. Жарыя кошуу жалпыга көрүнбөйт жана байланыш/заказ сервери жок. Чыныгы ишке киргизүү үчүн маалымат базасы, сервер/API, авторизация, админ-панель, текшерүү жана модерация, купуялык шарттары керек.

## GitHub Pages'ке жайгаштыруу

1. ZIP архивди телефонго же компьютерге жүктөп, **ичиндеги файлдарды чыгарып алыңыз**.
2. GitHub'та жаңы репозиторий түзүңүз (мисалы `paida-kg`).
3. Репозиторийдин эң үстүңкү деңгээлине `index.html`, `styles.css`, `app.js`, `favicon.svg` файлдарын жүктөңүз. `index.html` папканын ичинде терең жайгашып калбасын.
4. Репозиторийден **Settings → Pages** бөлүмүн ачыңыз.
5. **Deploy from a branch** тандаңыз; `main` жана `/ (root)` коюп, **Save** басыңыз.
6. GitHub берген сайт шилтемесин ачыңыз. Биринчи жарыялоо бир аз убакыт алышы мүмкүн.

GitHub Pages — статикалык фронтенд үчүн гана. Ал өзү эле каттоо, жалпыга жарыялоо, маалымат базасы же админ-панель бербейт.

## Кийинки техникалык этап

- Backend жана PostgreSQL/Supabase маалымат базасы.
- Телефон аркылуу кирүү/колдонуучу профили.
- Чыныгы жарыяларды серверге сактоо жана модерация.
- Админ-панель, спамдан коргоо жана даттануу механизми.
- Чыныгы бааларды/арзандатууларды ишенимдүү булактан жаңылоо.
