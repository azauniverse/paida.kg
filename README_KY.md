# PAIDA KG — API менен туташтырылган фронтенд

Бул папка GitHub Pages репозиторийиндеги негизги файлдарды жаңыртуу үчүн.

Файлдар:
- `index.html`
- `styles.css`
- `app.js`
- `favicon.svg`
- `config.js` — Cloudflare Worker API дареги коюлган.

## GitHub'ка жаңыртуу
1. Репозиторийди ачыңыз: `https://github.com/azauniverse/paida.kg`
2. `Add file` → `Upload files` тандаңыз.
3. Бул папкадагы беш файлды тандап жүктөңүз (папканын ичиндеги файлдар гана, ZIP'тин өзүн эмес).
4. `Commit changes` басыңыз.
5. GitHub Pages жаңырганча бир аз күтүңүз, анан сайтты жаңыртып көрүңүз.

## Маанилүү
- API дареги `https://paida-kg-api.azataycan2002.workers.dev` деп коюлган.
- API аркылуу жаңы жарыялар D1 базасына `pending` статусу менен сакталат.
- Алар сайтта автоматтык көрүнбөйт: адегенде модерация керек.
- Демо карточкалар дагы мисал катары кала берет.
